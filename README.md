# iamunnip.github.io

Personal portfolio of Unni P, a Site Reliability Engineer with 9+ years of experience in Linux, cloud and DevOps.

**Live site:** https://iamunnip.github.io/

## Tech stack

Plain HTML and CSS, hosted on GitHub Pages. There are no dependencies, no JavaScript and no build step.

## Project structure

| File | Purpose |
| :--- | :--- |
| `index.html` | Page content: about, career, skills and contact |
| `styles.css` | Styles, including light and dark themes |
| `.nojekyll` | Tells GitHub Pages to skip the Jekyll build |

## Run locally

Open `index.html` in a browser, or start a local server:

```bash
python3 -m http.server 8000
```

Then go to http://localhost:8000.

## Deployment

GitHub Pages serves the root of the `main` branch. Make changes on `develop`, then merge into `main` with a pull request. The site updates shortly after the merge.
